## 🚀 핵심 기능
1. **AI 페트병 인식**: 딥러닝 모델을 활용한 투명 페트병 자동 분류 및 인식.
2. **분리배출 인식 게임**: 배출 데이터와 연동된 Unity 기반의 게이미피케이션 요소 도입.
3. **사용자 인증 시스템**: 관리자 및 사용자 로그인/로그아웃 및 계정 정보 수정.
4. **실시간 데이터 모니터링**: 어드민 앱을 통한 페트병 수거량 및 계정 상태 관리.
5. **게임 라이프 시스템**: 게임 내 실시간 하트 차감 로직 및 UI 연동.
